# 极简时间戳日记 (Minimal TimeStamp Diary)

一个纯本地、无网、极度克制的 Android 个人时间戳记录工具。

## 💡 核心功能
- **秒开秒记**：输入文字，自动获取设备本地时间戳（精确到分钟）。
- **AM/PM 分区**：按上下午严格分区展示，回归最原始的日记体验。
- **日历回顾**：右滑进入月历，有记录的日期打点，支持精准跳转年份/月份。
- **倒数日**：支持自定义目标倒计时（如考研/纪念日）。
- **绝对隐私**：无任何网络权限，数据仅存于本地 Room 数据库，拒绝云端上传。

## 🛠 技术栈
- **UI框架**：Kotlin 2.0 + Jetpack Compose (Material 3)
- **数据存储**：Room Database (基于 KSP 注解处理)
- **架构**：单 Activity 架构，MVVM 模式，StateFlow 驱动
- **时间管理**：全面采用 `java.time` (LocalDate/YearMonth) 处理跨天与时区边界

## 📱 运行环境
- 最低支持 Android 8.0 (API 26)
- 安装包体积仅 6.35 MB

## 🚀 编译指南
1. 克隆本仓库。
2. 使用 Android Studio 打开，等待 Gradle 同步完成。
3. 点击 Run 即可编译运行。
